## 활용 팁

1. **롱테일 조합**: "지역(동네) + 업종 + 수식어" 구조로 확장 (예: *범어동 조용한 브런치 카페*).
2. **의도별 분류**: 정보형(가볼만한곳) / 비교형(맛집 추천) / 거래형(예약·문의)으로 나눠 콘텐츠 매핑.
3. **지역 표기 다양화**: "대구 수성구" / "수성구" / "범어동" 등 상·하위 지역명을 모두 활용.
4. **지도 검색 최적화**: 네이버 플레이스·카카오맵 등록 시 동네명·역명·랜드마크를 함께 표기.
5. **검증 필수**: 위 키워드는 일반 지식 기반 정리이므로 실제 검색량·트렌드는 별도 도구로 확인하세요.
